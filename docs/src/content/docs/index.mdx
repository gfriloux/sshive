# SSHive

**A simple, secure, and principled SSH key manager.** One key per service. Deployed easily. Renewed wisely.

SSHive is a desktop application (Tauri v2 + Svelte 5, Rust backend) that centralizes your SSH keys, protects them with GPG, and automates their deployment to GitHub, GitLab, and your SSH servers.

## Philosophy: One key per service

SSHive follows a simple and healthy principle: **each critical service receives its own SSH key**, rather than reusing a generic key.

Benefits:

- **Isolation** — the compromise of one key exposes only that service
- **Independent rotation** — renewing a key doesn't disrupt other services
- **Clear audit** — trace exactly who has access to what
- **Compliance** — satisfies security audit requirements

## Security First

- **GPG encryption** — all secrets (API tokens, passphrases) are encrypted at rest
- **Hardened process** — core dumps and ptrace blocked at startup
- **Pure Rust SSH key re-encryption** — passphrases never exposed on command line
- **Strict permissions** — config/secrets files with mode `0600`
- **Local audit** — append-only log of all rotations and revocations

See the [Security Policy](/reference/security/) for full details.

## Requirements

- **NixOS or Linux with Nix** — SSHive distributes via Nix flake
- **GPG** — configured and capable of generating or importing keys
- **SSH** — working SSH infrastructure (keys, config, permissions)
- **Optional: YubiKey** — for hardware security key sk-ed25519
