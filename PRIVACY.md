# Privacy Policy

SSHive is a desktop application that runs entirely locally. This document describes what data it stores and what network connections it makes.

## Data stored locally

SSHive stores the following data on your machine only:

- **`~/.config/sshive/config.yaml`** — service names, connection parameters (host, user, port), references to SSH keys by UUID. Permissions: 0600 (readable only by you).
- **`~/.config/sshive/secrets.yaml.gpg`** — API tokens and other secrets, encrypted with your GPG key. Readable only by the GPG key you selected at first launch.
- **`~/.ssh/sshive_<service>_<date>`** and **`.pub`** — SSH key pairs generated by SSHive. Private key permissions: 0600.

## Network connections

SSHive makes **outgoing connections only**, initiated explicitly by you:

| Operation | Destination | Protocol |
|-----------|-------------|----------|
| Deploy key (automatic) | Your configured server | SSH (port 22 or custom) |
| Verify connection | Your configured server | SSH |
| Revoke key | Your configured server | SSH |

SSHive never connects to Anthropic servers, analytics services, or any third party. There is no telemetry, no crash reporting, and no update check.

## External processes

SSHive invokes the following local programs as subprocesses:

- `ssh-keygen` — key generation and passphrase management
- `ssh-copy-id` — automatic key deployment
- `ssh` — connection verification and key revocation
- `gpg` — secret encryption/decryption and key management
- `pinentry-*` — passphrase collection (runs in a separate window)

## Data you control

- All data is stored in standard locations under your home directory.
- Deleting `~/.config/sshive/` removes all SSHive configuration.
- SSH keys generated by SSHive are standard OpenSSH files; they can be used with any SSH client.
- The GPG-encrypted secrets file can be decrypted with `gpg --decrypt` using your own key.
